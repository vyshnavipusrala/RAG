## Chunk Enhancement Techniques in RAG

**Chunk enhancement** = Improving chunks before storing them in the vector database to improve retrieval quality.

1. **Contextual Chunking**

   * Adds surrounding context to make chunks more understandable.

2. **Contextual Retrieval**

   * Adds document title, section, or background information to each chunk.

3. **Metadata Enrichment**

   * Adds metadata like **document name, page, section, date, and department**.

4. **Chunk Summarization**

   * Creates a short summary of each chunk for better semantic matching.

5. **Hypothetical Questions**

   * Generates possible questions that the chunk can answer and uses them for retrieval.

6. **Parent-Child Chunking**

   * Uses small child chunks for precise retrieval and larger parent chunks to provide context.

7. **Chunk Overlap**

   * Overlaps neighboring chunks to preserve context across boundaries.

8. **Semantic Chunking**

   * Splits text based on **meaning and topic** rather than only fixed token size.

### Remember:

> **Better chunks + better context → better retrieval → better RAG answers.**
