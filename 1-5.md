# Why is RAG required when an LLM is already powerful?

* LLMs don’t know your private/company data.
* LLM knowledge can be outdated, and LLMs can hallucinate.
* You don’t need to retrain the LLM every time the data changes.
* RAG provides sources/citations.

# Is RAG still relevant in the era of long-context LLMs?

Yes, RAG is still important even with large-context LLMs.

Large-context models have limitations:

* Lost-in-the-middle
* Higher API costs
* Increased latency

As the context becomes large, it can be difficult for the LLM to find the most relevant information, which affects the quality of responses. Processing large amounts of text for every request increases the number of tokens, so costs and latency are also affected.

# Challenges of RAG Systems

| Retrieval Problems | Generation Problems |
| ------------------ | ------------------- |
| Wrong chunks       | Hallucination       |
| Poor chunking      | Poor reasoning      |
| Bad embeddings     | Context overload    |
| Query ambiguity    | Unsupported answers |
| Stale documents    |                     |

# Effective strategies to reduce latency in RAG systems

* Reduce the number of retrieved documents.
* Use a fast vector database.
* Reduce or limit unnecessary reranking.
* Parallelize independent operations.
* Reduce the number of LLM calls.
* Use faster and smaller models.
* Reduce context size.
* Cache embeddings and frequently asked questions and responses.

# Explain R, A, G in RAG

**R — Retrieval**
The process of searching for and fetching the most relevant information from external knowledge sources for a given user query.

**A — Augmentation**
The process of including the retrieved context, instructions, and query in the prompt.

**G — Generation**
The process where the generator LLM processes the prompt to generate an accurate and relevant response.

# Simple RAG Workflow

```text
User Query
    ↓
Query
    ↓
Retriever
    ↓
Search Knowledge Base
    ↓
Retrieve Relevant Documents/Chunks
    ↓
Augment Prompt
(Query + Retrieved Context)
    ↓
LLM
    ↓
Generated Response
    ↓
Final Answer
```
